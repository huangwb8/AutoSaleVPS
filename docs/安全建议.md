# AutoSaleVPS 配置与部署安全

## 限制配置的访问范围

TOML 保存在 `wp-content/uploads/autosalevps/`。仅允许必要的 WordPress 进程和站点运维账号写入这个目录，并在 Web 服务器或反向代理阻止直接下载其中的 TOML 和日志。API key 通过后台保存到 WordPress 数据库，备份时按站点凭据管理。不要把密钥放进 TOML、发布包或截图。

修改 `model.toml` 的 `base_url` 前，先确认它是你信任的模型服务。模型调用会给该服务发送已配置的 API key，也会发送用于库存判断或整理规格的数据。若模型服务或站点配置曾被他人改动，先审查其地址并轮换密钥。

## 限制采集服务的网络范围

商品规格和库存均读取 `valid_format`，推广链接只用于展示。后台保存时会检查已配置商品的 `sale_format` 和 `valid_format` 是否能展开为含商品编号的 HTTP/HTTPS URL。这个检查只检查格式，部署时仍应仅配置可信的公开厂商地址，并用网络策略限制 WordPress 和浏览器服务的访问范围。

FlareSolverr 的 Compose 示例只在 Docker 网络内提供服务，不映射宿主机端口。不要把无独立认证的采集接口开放到公网；详细的网络与健康检查见[浏览器采集指南](browser-fetching.md)。
